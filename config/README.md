# Конфигурация

- `indicator-registry.json` — реестр показателей и их метаданных;
- `validation-policy.json` — политика автоматической проверки;
- `import-pipeline.json` — параметры intake/staging pipeline.

Изменения конфигурации должны проходить те же проверки эквивалентности и валидации, что и изменения расчётной логики.
