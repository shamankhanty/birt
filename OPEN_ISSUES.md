# Открытые вопросы после фиксации v5.0.0

## Незакрытые программные ошибки

**Подтверждённых незакрытых программных ошибок нет.**

Контроль качества v5.0.0: staging PASS (17 адаптеров), validation 15/15 PASS, calculation equivalence 38/38 PASS, metadata equivalence 38/38 PASS, полная сборка PASS, автотесты 129/129 PASS.

## Ожидаемые данные и решения

1. **Амбулаторные эпикризы на уровне МО.** Для августовского рейтинга отсутствует сопоставимый полный августовский источник с числителем и знаменателем по каждой МО. Доступный набор июня–июля не возвращать в рейтинг до получения полного августа.
2. **Доля ошибок регистрации СЭМД.** Августовский файл содержит 785 939 отказов, 32 категории и 213 организаций/источников, но не содержит знаменатель всех обработанных запросов. До получения знаменателя не рассчитывать долю и не присваивать оценку качества.
3. **МАХ — запись к врачу на телеконсультацию по МО.** В проекте есть только оперативный накопительный разрез на 07.09.2026. Полные июль и август по МО не рассчитывать до появления граничных месячных срезов.
4. **МАХ — динамика ТМК и ЛВН.** Полный август рассчитан как разность накопительных срезов на 31.07 и 31.08. Полного июля нет, поэтому фильтры роста/падения не активировать до появления второго сопоставимого полного месяца.
5. **Полный сентябрь.** Оперативный срез 07.09 не заменяет августовский рейтинг. Пересчёт рейтинга возможен после закрытия сентября и получения сопоставимых полных данных.

Презентация в рамках v5.0.0 не изменялась. Актуальной остаётся версия `09_09_2026_А_Р_Абашев_показатели_3.pptx`.
