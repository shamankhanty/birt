# Открытые вопросы после подготовки v5.4.3

## Незакрытые программные ошибки

На момент подготовки v5.4.3 **подтверждённых незакрытых программных ошибок нет**. Финальный статус определяется после полного CI. Production остаётся на v5.4.2 до отдельного разрешения на публикацию.

## Ожидаемые данные и методологические ограничения

**Выписные эпикризы — августовский рейтинг.** Оперативный срез 11.09 пересчитан корректно: числитель РЭМД ЕГИСЗ, знаменатель случаев госпитализации, OID↔OID. Полный августовский набор по МО был сформирован по прежнему источнику числителя и временно исключён из рейтинга до пересчёта по полному августовскому РЭМД-источнику.

1. **Доля ошибок регистрации СЭМД.** Оперативный недельный источник 07–13.09.2026 содержит 2 046 140 отказов, но не содержит знаменатель всех обработанных запросов. До получения знаменателя показывать абсолютное количество, категории и МО; долю и рейтинг качества не рассчитывать.
2. **500+ в заслушивании.** Неполный сентябрьский срез используется только как оперативный справочный контроль МО. Он не заменяет полный август и не входит в месячный рейтинг без отдельной утверждённой методики.
3. **Амбулаторные эпикризы на уровне МО.** Для августовского рейтинга отсутствует сопоставимый полный августовский источник с числителем и знаменателем по каждой МО. Старый июнь–июль не возвращать в рейтинг.
4. **МАХ — запись к врачу.** Источник по записи содержит муниципалитет × месяц, без идентификатора МО. Не распределять искусственно между МО и не включать в рейтинг МО.
5. **МАХ — ТМК и ЛВН: полный июль.** Нет сопоставимого накопительного среза на 30.06; полный июль и динамику август ↔ июль не рассчитывать до появления источника.
6. **Полный сентябрь.** До закрытия календарного месяца август остаётся последним полным месяцем рейтинга.
7. **Ручные факты РТ.** При поступлении первичных источников заменить ручной ввод и повторно подтвердить числители/знаменатели для соответствующих федеральных/коллегиальных показателей.
