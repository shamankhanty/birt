# Forced GitHub Pages redeploy

Причина: опубликованный сайт продолжал показывать предыдущий артефакт v5.2.2, несмотря на успешный workflow. Этот коммит принудительно запускает новую сборку из актуальной ветки main, где присутствуют UI-изменения v5.2.2.

Контрольные признаки актуальной сборки:
- фильтр «Все, кроме «В контракте»» в расширенной сводке;
- переключатель «Запись к врачу / ТМК / ЛВН» в разделе МАХ;
- отсутствует дублирующий блок «Региональный контроль · МАХ».
