# Методологические инварианты дашборда

Этот раздел фиксирует правила, которые нельзя менять при очередном обновлении данных без отдельного методологического решения.

## Общие правила

- Один показатель рассчитывается один раз и затем используется во всех разделах.
- Отсутствие строки в источнике не подменяется нулём.
- Числитель и знаменатель должны относиться к одному периоду и сопоставимому составу МО.
- Региональный итог долевого показателя считается как отношение суммарного числителя к суммарному знаменателю, а не как среднее процентов МО.
- Изменение источника, периода или методики не считается улучшением показателя.
- Значения выше 100% не ограничиваются искусственно, если таков фактический результат источника.
- Неприменимый показатель исключается из знаменателя рейтинга и из приоритета заслушивания.
- Случаи краткого ввода показываются справочно и не влияют на баллы.
- КДЛ сохраняются в мониторинге, но исключаются из интегрального рейтинга.

## Периоды

- Последний полный месяц рейтинга v5.0.0: август 2026.
- Сопоставимый предыдущий месяц: июль 2026.
- Срез 07.09.2026 является оперативным и не заменяет полный месячный рейтинг.
- Врачи и показатели «500+» обновляются только по полному месяцу.

## Профилактика 122/228

Текущий утверждённый расчёт: `MAX(СЭМД 122; СЭМД 228)` отдельно по каждой МО, затем суммирование по региону. Не суммировать 122 и 228 между собой для одной МО.

## Ошибки регистрации СЭМД

Абсолютное количество отказов не является долей ошибок и не является рейтингом качества без знаменателя всех обработанных запросов на регистрацию по соответствующему периметру.

## МАХ

- Годовые планы Республики Татарстан не переносятся на отдельные МО.
- Полный август по ТМК и ЛВН рассчитывается как разность сопоставимых накопительных срезов 31.08 и 31.07 по каждой МО.
- Срез 31.07 нельзя выдавать за полный июль.
- Рост/падение показывается только при наличии двух сопоставимых полных месяцев.
- Подтверждённый ноль и отсутствие строки — разные состояния.

Полный актуальный набор правил и контрольных значений находится в `STATE.md`.
