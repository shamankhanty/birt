# Выбор МО перед открытием карточки ФРМР

Первое открытие «Карточка МО и действия» показывает пустой выбор МО вместо автоматически выбранной РКБ. До явного выбора не выводятся её OID, статистика или должностные записи. Удалён резервный переход к первой МО списка.

Поиск занимает ширину карточки, имеет заметную рамку, лупу и подпись. Подсказка показывает порядок: МО → должность → подразделение → записи для проверки. После выбора видны название МО, OID и кнопка «Сменить МО». Смена возвращает к пустому поиску и сбрасывает должность/СП/фильтры записей. Переход по названию МО из обзора сразу открывает именно выбранную организацию. Переключение охвата также сбрасывает выбор.

Проверены локальный HTML и экран 390 px: первый вход без выбора и без данных РКБ, отсутствие выбора по Enter с пустым поиском, поиск полного OID, выбор клавиатурой, смена МО, сообщение о ненайденной МО, выбор другой МО, прямой переход из обзора. Ошибок JavaScript и выхода страницы за ширину экрана нет. Прежние 36 производственных наборов не изменены. Новые наборы всех специальностей и ФРМО также не менялись. TypeScript: прежние 19 ошибок, новых нет.
