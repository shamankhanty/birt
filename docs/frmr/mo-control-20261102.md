# Основной контроль ФРМР на уровне МО · 02.11.2026

Основание: согласованное продолжение предложения после замечаний К.О. Нургатиной. По умолчанию показывается только отсутствие должности на уровне МО. Второй этап, когда должность есть в МО, но не совпадает СП, вынесен в отдельный режим «Привязки СП · справочно». Два режима не суммируются в основной итог, сортировки и фильтры работают внутри выбранного режима.

## Источники и применимость

Срез ФРМР 29.10.2026, исходный перечень 8264 должностных записей. Прежние исключения сохранены. При чтении исходного столбца «Тип структурного подразделения» обнаружены ещё 14 записей типа «Скорая медицинская помощь», которые невозможно было определить по наименованию СП. Они исключены по ранее утверждённому правилу: всего скорая помощь 900, стажёры 129, средний лабораторный персонал 313. Итого исключено 1342; остаток 6922.

- Основной контроль МО: 4388 записей, 136 МО из 137, 70 наименований должностей.
- СП справочно: 2534 записи, 117 МО, 69 наименований должностей.
- 4388 + 2534 + 1342 = 8264. Это записи, не уникальные люди.

`app/frmr-sp-types.json` содержит подтверждённый тип по полному OID СП: 1804 OID, без конфликтов. SHA-256 источника совпадает с исходной сверкой. Фильтр использует столбец 17 (нумерация с нуля) Excel, а не угадывание типа по названию. Сохранены административно-хозяйственные, лабораторные и прочие применимые СП; тип не доказывает работу только по ОМС или только платно. Неизвестный тип обозначается явно. Генерация карты включена в scripts/frmr/build-all-specialties.py.

Все специальности сохраняются; ограничение перечнем 14 специальностей отдельного показателя не применяется. СЭМД не оценивается по отсутствию должности в ГИС.

## Интерфейс

На уровне МО после выбора должности сразу доступны все её записи данного уровня по выбранной МО, номер строки исходника и последние четыре цифры СНИЛС. СП можно раскрыть в строке справочно. Предварительный выбор СП не требуется. В справочном режиме сохранён маршрут по подразделениям. Смена режима и типа сбрасывает выбранную должность, СП и поиск по последним цифрам, сохраняя явно выбранную МО. Автоматического выбора РКБ нет.

Общий исходный итог после исключений подписан отдельно; его нельзя принять за основной показатель. Архив 22.10 и отдельные привязки ФРМО не пересчитываются. Изменение охвата не является динамикой или улучшением.

## Проверка

Баланс записей и всех уровней агрегации, непересечение режимов, разбиение по всем типам СП, сохранение административных и диагностических специальностей, отсутствие мутации исходника; браузерная проверка основного маршрута, справочного СП, фильтра типов, архива и мобильного экрана 390 px.
