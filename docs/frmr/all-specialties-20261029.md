## Привязки ФРМО, 30.10.2026

Источник: «Привязка_СП_и_отд._к_ФРМО 30.10..2026 ВСЕ СПЕЦ. Для ВКС МЗ РТ.xlsx». Один элемент — строка отделения ГИС; это не число уникальных СП и не число МО.

В детализации 3 385 строк по 135 кодам МО. По проверяемым полям отклонения есть в 2 043 строках, в 1 342 их нет. Причины пересекаются: нет OID СП у филиала — 422; нет OID СП у отделения — 424; разные OID — 1 025; разные привязанные наименования ФРМО — 1 959; активное отделение в неактивном СП по выгрузке — 135. Различие наименований требует проверки справочника и не доказывает неправильный OID.

Исходная сводка показывает 3 351: формула VLOOKUP берёт значение колонки M, которая лишь считает строки подряд в группе МО. Колонка L «Цвет» чередует оформление групп, не кодирует ошибку. Поэтому ни M, ни L не используются как признаки ошибок. В сводку не включены 34 строки по 8 кодам МО; все сохранены в новой детализации и помечены.

По Спасской ЦРБ присутствуют три родительских OID, 1094 / 1132 / 18650. В интерфейсе указана необходимость проверки действующих и исторических привязок; автоматического объединения, изменения реестра МО и переноса числителей между МО нет. Сопоставимой прошлой детализации по тем же правилам нет — динамика ошибок привязки не рассчитывается.
