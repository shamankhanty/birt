# МАХ в приоритете заслушивания — 02.11.2026

По прямому указанию пользователя ТМК и ЛВН МАХ включены в оперативный приоритет.
Персональные накопительные планы — config/max-targets-2026.json, строго по OID и месяцу факта.
Дефицит = MAX(0, план МО − факт МО). Источник текущего факта: 01.01–28.10.2026;
контрольная точка плана — 31.10.2026. Неполный октябрь не объявляется закрытым месячным результатом.

МАХ входит в существующий блок цифровых сервисов (20%). Внутри блока шесть показателей
равновесны: ЕПГУ, срок рассмотрения ЕПГУ, рождение, смерть, ТМК МАХ и ЛВН МАХ.
При отсутствии регионального дефицита показатель не забирает вес у других; блоки
помощи 70%, готовности 10% и итоговые веса приоритета 60/20/10/10 сохранены.
Каждая МО получает долю регионального дефицита по каждому показателю и взвешенный вклад.
Подтвержденный ноль учитывается; отсутствие строки не становится нулём.
МО вне утверждённого перечня планов МАХ не оцениваются по МАХ.
Устойчивое невыполнение МАХ не начисляется без сопоставимого предыдущего плана.
Сентябрьский месячный рейтинг и исторические снимки заслушивания не меняются.

Контроль примера со скриншота: ТМК 1580 при плане 6865 → дефицит 5285;
ЛВН 1494 при плане 3497 → дефицит 2003. План не умножается на 100 и не
подменяется общерегиональным значением 10000.
