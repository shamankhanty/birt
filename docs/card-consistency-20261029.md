# Согласованность карточек, меню и статусов — 29.10.2026

Проверены 69 самостоятельных карточек: 41 по соглашению и 28 по коллегии.

Исправления:
- Общий расчёт пяти показателей ТВСП/КДЛ/СМП использует принятые итоги объектов/зданий из `unit-data.json`. Проценты, числитель, знаменатель и дата больше не подставляются из старого статического значения или детализации по СП.
- «Не менее» — нижняя граница; «не более» — верхняя. ЕПГУ ≤2 рабочих дней: 84,5678% при минимуме 90% — отставание.
- Фильтры и текущие региональные статусы берутся из той же оценки, что зона карточки. Статусы федерального исходника остаются историческими данными, но не фильтруют текущие результаты РТ.
- Для количественных компонентов приоритет имеют поля расчёта, а не разбор текста подписи.
- Пропуски итогов объектов остаются пропусками; старый процент и ноль вместо них не подставляются.
