# Аудит показателей «500+ СЭМД» по Issue #100

Дата проверки: 20.10.2026. Источник: `Отчёт_по_врачам_сформировавших_СЭМД _01.10.-19.10.(Выгрузка из BI 19.10.).xlsx`, SHA-256 `57a377e5963e87cc30acb60e8b10268611f0a176aa53d282314f9a171cba8289`.

## Результат

- В первичном файле проверены 124 МО; строки хотя бы по одной из девяти специальностей есть у 112 МО. Ещё 12 МО отсутствуют в специальном своде и сохранены как «не входят в источник», а не как нулевые.
- Проверено 720 комбинаций `МО × специальность`: 381 PASS, 339 WARN, 0 FAIL.
- Все 720 числителей и знаменателей дашборда совпадают со сводным листом первичного Excel.
- Все девять сумм по МО совпадают с региональными итогами листа `Врачи по спец-тям_По субъекту`.
- 307 WARN связаны с несовпадением наблюдаемого состава детализации и федерального свода либо с неоднозначностью нескольких строк одного OID; 32 WARN — с отсутствием подходящих строк детализации. Эти строки нельзя автоматически пересчитывать без правил отбора ФРМР и идентификаторов отдельных СЭМД.
- Подтверждённых критических расхождений между первичным сводом и дашбордом нет.

Полный построчный реестр, включая МО, OID, специальность, период, источник, сводные и диагностические компоненты, отклонения и причины, находится в `docs/physician500-reconciliation-20261019.json`.

## Сабинская ЦРБ — стоматологи

Официальное значение `2/5 = 40%` подтверждено детализацией без суммирования неоднозначных строк.

- В знаменатель входят пять уникальных OID работников с должностями: врач-стоматолог, врач-стоматолог-терапевт и врач-стоматолог детский.
- Два работника имеют отдельную допустимую строку свыше 500 СЭМД: OID `2022.5547` — 569; OID `2022.68076` — 525.
- OID `2023.4380784` с нулём СЭМД входит в знаменатель ФРМР. Его исключение из предварительного подсчёта уменьшало знаменатель с пяти до четырёх среди допустимых должностей.
- OID `2022.181023` (709) и `2022.866538` (540) — стоматологи-хирурги; они не входят в точный перечень должностей показателя «Стоматолог».
- Два стоматолога-ортопеда также не входят в этот показатель.

Предварительные `4/6` получились из-за включения двух стоматологов-хирургов и одновременного исключения врача с нулём СЭМД. Значение дашборда менять не требуется.

## Изменения контроля

- Введён точный разрешительный перечень должностей; похожие специальности больше не объединяются поиском подстроки.
- Один врач идентифицируется по `OID МО × OID работника × специальность`.
- Порог зафиксирован как строго свыше 500, то есть 501+.
- Несколько строк одного врача не суммируются в официальный факт. Сумма сохраняется только как диагностическая граница; переход через порог даёт WARN.
- Новый отчёт использует PASS/WARN/FAIL и не меняет официальный числитель, знаменатель, месячный рейтинг или историю.
- Конвейер сохраняет отдельный `physician500-audit.json` с полным перечнем проблем при каждом новом врачебном импорте.
