## Статус импорта в GitHub

Документация baseline уже зафиксирована в репозитории. Полный исходный пакет пока не распакован в GitHub через коннектор: доступная интеграция поддерживает запись текстовых файлов, но не массовую загрузку локального ZIP/дерева каталогов одним действием.

До завершения первичного импорта источником истины для полного набора исходников является указанный ZIP, а для актуальных правил и открытых вопросов — `STATE.md` и `OPEN_ISSUES.md` в этом репозитории.

После первичного импорта дальнейшие изменения рекомендуется вести непосредственно через GitHub с отдельными коммитами и Issues.
