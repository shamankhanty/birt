# RT Health Digital Dashboard

Репозиторий исходного кода и технической документации дашборда цифровизации здравоохранения Республики Татарстан.

## Важно

Репозиторий публичный. Не размещать в нем:
- персональные данные;
- медицинскую информацию о пациентах;
- служебную или конфиденциальную информацию;
- необезличенные выгрузки медицинских организаций;
- пароли, токены, ключи API и иные секреты.

В репозитории допускается хранить только код, обезличенные конфигурации, методики расчетов и техническую документацию, безопасные для публичного размещения.
