## Правила расчётов

- Один показатель рассчитывается один раз и переиспользуется во всех разделах.
- Отсутствие данных не заменяется нулём.
- Изменение методики, источника или исправление ошибки не считается динамикой.
- Для долевых показателей обязательны проверка числителя, знаменателя, периода и источника.
- Для рейтинга используются только сопоставимые полные календарные месяцы.
- В режиме **«Оперативно»** раздела показателей сравниваются текущая выгрузка и непосредственно предыдущая подтверждённая выгрузка независимо от числа дней между ними; обе даты показываются явно.
- Для количественных показателей оперативная разница показывается в абсолютном значении и, при ненулевом предыдущем значении, в процентах; для долевых показателей — в процентных пунктах.
- Для **накопительных долевых показателей с подтверждёнными компонентами** дополнительно показываются числитель и знаменатель обоих срезов и изменение каждого компонента. Если накопительный числитель или знаменатель уменьшился, это помечается как аномалия качества данных и требует проверки источника/состава; такое снижение не скрывается.
- Компоненты предыдущего среза используются только если они были сохранены/подтверждены; они **не восстанавливаются из процента** и отсутствие компонента не заменяется нулём.
- Если методика, источник или состав расчёта между выгрузками изменились, изменение не трактуется как динамика.
- Доля ошибок РЭМД не рассчитывается без знаменателя всех обработанных запросов; абсолютное число ошибок не называется рейтингом качества.

## МО для заслушивания

- Приоритет МО строится по вкладу в недостижение целей РТ для применимых долевых показателей:
  - целевое количество = план × знаменатель МО;
  - дефицит = MAX(0; целевое количество − фактический числитель);
  - вклад МО в недостижение РТ, п.п. = дефицит МО / общий региональный знаменатель показателя × 100.
- П.п. разных показателей не выдаются за один показатель; агрегированный результат называется **индексом влияния**.
- Исторический вклад к дате заслушивания рассчитывается только при наличии сопоставимого регионального знаменателя в baseline.
- **500+** добавлен в карточки применимых МО как **оперативный справочный контроль текущего состояния**. Он не меняет августовский месячный рейтинг. Нет строки = «Нет данных», а не невыполнение.
- Для уже заслушанных МО текущие значения сравниваются с baseline только при сопоставимости срезов.

## МАХ

- ТМК и ЛВН после ТМК представлены как два самостоятельных показателя в меню и интерфейсе; объединённое значение не используется.
- Оперативный текущий срез ТМК/ЛВН: **01.01–11.09.2026**.
- Предыдущий сопоставимый срез: **01.01–07.09.2026**.
- Подписи периодов формируются из фактических source cut, а не из старых августовских констант.
- Оперативная динамика ТМК/ЛВН строится как сравнение выгрузок **07.09.2026 → 11.09.2026**; интервал в 4 дня показывается как интервал между срезами, а не называется неделей.
- Официальные годовые планы РТ сохраняются отдельно: запись к врачу — 654 000; ТМК — 193 000; ЛВН — 99 000. Они не делятся на месячные планы МО.

## История обновлений

- Пользовательская история агрегируется: одна карточка на календарный день; технические обновления одного дня объединяются.
- После завершения недели технические версии агрегируются в одну пользовательскую запись за неделю.
- CI/патчи/отладочные итерации остаются в GitHub и не выводятся отдельными карточками пользователю.
