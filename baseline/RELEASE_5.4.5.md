# Release candidate v5.4.5

Дата подготовки: 15.09.2026.

Статус: подготовлен к проверке, не опубликован.

## Изменения

- режим «Оперативно» для всех показателей 500+ использует отдельный текущий срез physician-weekly-snapshot; полный август остаётся только в режиме «Месяцы»;
- текущий оперативный срез 11.09 показывает региональный факт и компоненты числитель/знаменатель; отсутствие более раннего оперативного файла не подменяется августом;
- pipeline сохраняет предыдущий оперативный срез 500+ при следующей загрузке, чтобы автоматически появилась честная динамика выгрузка-к-выгрузке;
- история версий группируется по дате: несколько технических обновлений одного дня отображаются одной пользовательской карточкой.

Production не публиковать без отдельной команды.
