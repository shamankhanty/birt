# Release candidate v5.4.3

Дата подготовки: 15.09.2026.

Статус: подготовлен к проверке, не опубликован.

## Изменение

В разделе «Показатели» режим краткосрочной динамики изменён с условного сравнения «неделя к неделе» на сравнение **текущей выгрузки с непосредственно предыдущей подтверждённой выгрузкой**.

- переключатель «Неделя» заменён на «Оперативно»;
- в карточках явно показываются даты предыдущей и текущей выгрузок;
- показывается разница между выгрузками;
- количественные показатели дополнительно показывают относительное изменение, когда предыдущая база не равна нулю;
- для долевых показателей изменение показывается в процентных пунктах;
- в таблице МО отображаются обе даты, абсолютная разница и относительное изменение;
- отсутствие предыдущего значения не заменяется нулём;
- месячная динамика остаётся отдельной и строится только по сопоставимым полным месяцам.

Для МАХ текущий оперативный срез 11.09.2026 сравнивается с предыдущим подтверждённым срезом 07.09.2026. Интервал 4 дня показывается явно и не называется неделей. ТМК и ЛВН остаются самостоятельными показателями.

## Ограничения

- значения исходных показателей не пересчитывались и не подменялись;
- годовые планы РТ не переносились на МО;
- изменение источника/методики не считается динамикой;
- production не обновляется до отдельной команды владельца проекта.
