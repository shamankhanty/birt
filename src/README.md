# Исходный код

Проект исторически организован без единой папки `src/`.

Канонические исходники находятся в:

- `app/` — интерфейс и рабочие наборы данных;
- `lib/` — расчётные и валидационные модули;
- `db/` — слой данных;
- `scripts/` — pipeline обновления и проверки;
- `tests/` — автоматические тесты.

Папка `src/` оставлена как навигационный указатель и не должна использоваться для дублирования файлов из `app/` или `lib/`.
